AWS Copilot CLI simplified the deployment and operation of containerized applications on Amazon ECS and AWS App Runner.

### How it works

1. Initialize an application and create a service. A service is the application component to deploy.
2. Define its configuration in a manifest, a file describing the desired service settings.
3. Deploy the service to an environment. The environment contains resources shared by its services.
4. Copilot uses AWS CloudFormation stacks to create application and service resources. A stack is a collection of resources managed as a unit. Copilot can also set up a CodePipeline deployment pipeline, a workflow that releases changes pushed to a Git repository.

Copilot offered these workload patterns:

| Pattern | Use |
|---|---|
| Load Balanced Web Service | Internet-facing ECS Fargate application with an Application Load Balancer. |
| Request-Driven Web Service | Web application on App Runner. |
| Backend Service | Internal service inside a virtual private cloud (VPC), an isolated virtual network, without a public endpoint. |
| Worker Service | Processes messages from Amazon SQS queues, which hold messages for consumers. |
| Scheduled Job | Runs containerized tasks on a schedule. |
| Static Site | Hosts a static website using CloudFront and an S3 bucket. |

### Exam cues

- If the question says a team needs a legacy CLI workflow for container applications, think AWS Copilot, because it simplified deployment on ECS and App Runner.
- If the question says an existing Copilot application needs a supported deployment path, think ECS Express Mode or AWS CDK, because AWS describes both as migration options.
- If the question says a team wants to manage existing Copilot infrastructure directly, think CloudFormation templates and stacks, because the team can adopt the generated resources.

### Remember

- AWS support for Copilot CLI ended on June 12, 2026. AWS no longer provides updates, security patches or technical support.
- Existing deployments continue to function without ongoing maintenance.
- As of November 2026, App Runner is closed to new customers; existing customers can continue using it.

> **Trap:** End of support does not mean existing deployments immediately stop working.
