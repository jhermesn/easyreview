title: Route 53
names: ["Amazon Route 53", "Route 53"]
summary: Host domain records, route DNS answers using policy and health, and resolve names across VPCs and other networks.
icon: route-53
---
Route 53 hosts Domain Name System (DNS) records, the entries that let clients look up a domain name. Routing policies and health signals determine which answers it returns. VPC Resolver looks up public and private names for virtual private clouds (VPCs); endpoints and forwarding rules connect those lookups to DNS servers on other networks.
